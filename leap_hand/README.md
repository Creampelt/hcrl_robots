# LEAP Hand

16-DoF open-source dexterous hand (https://leaphand.com).

- `leap_hand_right.urdf` / `leap_hand_left.urdf`, `meshes/` — from
  [dexsuite/dex-urdf](https://github.com/dexsuite/dex-urdf) (MIT, see `LICENSE.txt`);
  these are the URDFs supported by `dex-retargeting`.
- `usd/` — Isaac Lab USD from the official
  [leap-hand/LEAP_Hand_Isaac_Lab](https://github.com/leap-hand/LEAP_Hand_Isaac_Lab)
  extension (generated from the same dex-urdf model). Joints `a_0`..`a_15`.
